📖 Beginner OBS & Stream Deck Setup Guide ▼
1. Add Lower Thirds into OBS:

In OBS, add a Browser Source → Paste URL 1 (?view=overlay) → Set Width: 1920, Height: 1080. Keep it on top of your camera layer.

2. Add Ready-Made OBS Frames:

Select any frame in the Frame Editor tab, copy its URL, and add as a 1920×1080 Browser Source above your camera. The camera will fit seamlessly behind the transparent cutouts.

3. Add OBS Custom Browser Dock:

In OBS menu: Docks → Custom Browser Docks → Name: "Church CG" → URL: URL 2 (?view=control). Dock it neatly into OBS for one-click volunteer operation!

4. Stream Deck / iPad Touch Control:

Open URL 4 (?view=deck) in any browser or Stream Deck browser plugin. You get big touch buttons for every lower third, frame, marquee, and emergency clear!
